# 长期连载小说创作项目

本仓库用于管理长期连载小说的大纲、人物、世界观、正文、剧情记忆、写作计划与质量检查。当前已建立项目模板、导入大纲与人物资料，并整理两部原剧分集参考和用户确认的改写要求；尚未开始创作正文。

## 目录说明

- `01-小说大纲/`：全书大纲、分卷大纲、章节规划。
- `02-人物档案/`：人物设定、人物关系、人物状态。
- `03-世界观/`：世界规则、势力体系、时间线。
- `04-小说正文/`：每章独立保存，提供空白章节模板。
- `05-剧情记忆/`：剧情摘要、伏笔记录、已确认事实。
- `06-写作计划/`：当前进度、下一章目标。
- `07-质量检查/`：剧情重复、设定矛盾、章节质量报告。

## 使用约定

所有文档使用 UTF-8 编码与 Markdown 格式。尚未填写的模板仅含标题和空白栏目；导入工作稿中的待定项和建议不自动成为已确认设定。

获得创作指示后，可复制章节模板，以 `第0001章-章节标题.md` 的形式独立保存章节；分卷、人物等资料需要拆分时，可复制对应模板并使用明确的文件名。

创作前查阅大纲、人物状态、世界规则与剧情记忆；完成章节后同步相关记录，再执行质量检查。保留现有内容，修改既有设定前确认影响范围。

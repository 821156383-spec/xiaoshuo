## 单次记录模板

### 人物成长日志模板

| 记录字段 | 填写要求 |
| --- | --- |
| 人物/时间/章节 | 姓名、故事时间、章节范围 |
| 评估可信度 | 高/中/低，注明考核样本和信息来源 |
| 变化维度 | 只填写确有变化的能力，不要求九维全部上涨 |
| 变化前后 | 例如洞察82→84；无依据则不调整 |
| 变化原因 | 训练、实战、学习、复盘、职责变化或心理成长 |
| 状态修正 | 伤势、疲劳、心理压力、环境限制 |
| 性格变化 | 优势是否增强，缺陷是否改善或恶化 |
| 后续目标 | 下一阶段需要补足的能力短板 |

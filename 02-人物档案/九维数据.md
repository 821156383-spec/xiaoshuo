## 评估规范与成长日志字段

## 十三、九维能力档案管理规范

| 维度 | 定义 | 主要证据 |
| --- | --- | --- |
| 武力 | 体能、兵器、徒手、实战反应与技巧 | 专项测试、对练、实战记录 |
| 智谋 | 推演、计策、因果分析、复杂问题解决 | 沙盘推演、任务方案、复盘 |
| 洞察 | 观察细节、识人、判断异常、发现破绽 | 现场观察、审讯分析、识谎记录 |
| 统帅 | 指挥、调度、协作、临场控制 | 小队演练、联合行动、战场表现 |
| 谍报 | 潜伏、伪装、反跟踪、情报获取与保护 | 潜伏考核、渠道建设、反侦察 |
| 政治 | 权力判断、谈判、利益协调、外交与治理 | 谈判记录、政治判断、长期决策 |
| 医术 | 诊断、急救、治疗、药理与康复 | 模拟救治、病例、治疗结果 |
| 意志 | 抗压、忍耐、危机应对、执行稳定性 | 长时任务、审讯、极端情境观察 |
| 魅力 | 沟通、影响力、凝聚团队、建立信任 | 招募、协调、团队稳定性反馈 |

评分区间：0—39薄弱；40—59一般；60—69合格；70—79优秀；80—89精锐；90—94绝顶；95—99宗师；100理论极限。55分低于合格线。武力境界称谓仅为秘阁内部便于理解的分级，不代表江湖存在统一境界。

### 人物成长日志模板

| 记录字段 | 填写要求 |
| --- | --- |
| 人物/时间/章节 | 姓名、故事时间、章节范围 |
| 评估可信度 | 高/中/低，注明考核样本和信息来源 |
| 变化维度 | 只填写确有变化的能力，不要求九维全部上涨 |
| 变化前后 | 例如洞察82→84；无依据则不调整 |
| 变化原因 | 训练、实战、学习、复盘、职责变化或心理成长 |
| 状态修正 | 伤势、疲劳、心理压力、环境限制 |
| 性格变化 | 优势是否增强，缺陷是否改善或恶化 |
| 后续目标 | 下一阶段需要补足的能力短板 |
